# kmeans 世界観層と salience 顕著層の 2 系統並行抽出

## 何をやるか

同じ画像から `kmeans` (Lab 面積比) と `salience` (CAM16 顕著性) の 2 系統で並行に色抽出し、Neovim カラースキームのセマンティックグループに対して「世界観層」と「アクセント層」を使い分けて割り当てる。最終的な 16 色パレットは単一の wallust 呼び出しではなく、2 系統の結果を Neovim 割り当て層でブレンドして作る。

## なぜやるか

wallust v4 の 3 つの Palette は、画像種別によらず単一抽出では次のトレードオフから逃げられない。

- `kmeans` は面積比で代表色を取るため、白基調の画像で世界観を素直に出せる。一方で「瞳の赤」のような面積の小さい特徴色を dedup の網にかけて潰してしまう。
- `salience` は CAM16 顕著性で「目立つ色」を拾えるため特徴色は残るが、`--style light` でも大面積の支配色 (白〜銀のグラデ) を単色まで潰し、世界観のニュアンスが失われる。
- `ansi` は hue 6 バケットに無理やり振り分けるので、画像にない色を合成する性質上、世界観も推し色も保てない。

Cinderella 2 (白基調 + 赤瞳 + 水色ヘックス) のチューニングでこの限界が明確になった。`salience light low pastel` は瞳の赤と剣の青を拾うがキャラの「白の世界」の感覚を捨てる。`kmeans -k 16` は白〜銀〜水色のグラデを完璧に再現するが赤瞳を切り捨てる。`saturation` で底上げすると全色一律に派手になり、画像本来のグラデーションが破壊される。

Neovim カラースキームは「背景・前景・コメント」は画像のトーンに従ってほしい一方で、「Visual・Search・推し色」は鮮やかな特徴色を当てたい。この要求自体が 2 層構造なので、抽出側も 2 系統に分けるのが筋になる。
